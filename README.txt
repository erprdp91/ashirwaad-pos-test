AASHIRWAAD POS — iPhone TEST BUILD

Included: index.html, manifest.json, sw.js.
Features: normal/GST-demo bill selector, multiple line items, qty/rate, discount, simple tax calculation, payment mode, received amount/balance, receipt preview, share/copy, iOS print sheet, local test-bill history, CSV export.

IMPORTANT PRINTER LIMITATION:
This build does NOT send ESC/POS directly to the EZO BT-58D. It shares/copies receipt text and opens the iOS print sheet. Your Print 4 Printer app's successful self-test confirms the printer works with that app, not that another app can print to it. Direct integration needs a separate verified route.

iPhone install:
Host the files on an HTTPS website, open the URL in Safari, tap Share > Add to Home Screen. A local ZIP/file opened directly is not an installable PWA. After first online load, basic offline caching is enabled.

TEST ONLY:
GST field is a calculation demo, not a compliant GST invoice. No barcode scanning, product/stock database, purchases, supplier/customer ledger, cloud sync or direct printer driver in this starter test. Data is local to this browser and can be cleared. Do not use as official accounts or sole business records.
